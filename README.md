#  Personal Portfolio Website

A simple and responsive personal portfolio website built using **HTML and CSS**.  
The website presents my introduction, skills, projects, education, and contact information in a clean and user-friendly layout.

##  Features

-  Home section with a short introduction
-  About Me section
-  Skills section
-  Projects section
-  Education section
-  Contact section
-  Responsive design
-  Clean and simple UI

##  Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and layout

##  Website Sections

### Home
Introduces me and provides a quick overview of who I am.

### About Me
Contains information about my background, interests, and goals.

### Skills
Shows the programming languages and technologies I am currently learning or working with.

### Projects
Displays some of the projects I have worked on, along with a short description of each project.

### Education
Provides information about my academic background.

### Contact
Contains my contact details so that visitors can connect with me.

##  Purpose

The purpose of this portfolio is to create a simple online space where I can showcase my **skills, projects, learning journey, and achievements**.

It can also be used as a personal website when applying for internships, hackathons, projects, and future job opportunities.
